HelloController:

SimpleController (CRUD демо):

GET /api/demo/info - Информация
GET /api/demo/user/123 - Получить пользователя (с параметром пути)
GET /api/demo/search?name=Иван&page=2 - Поиск (query параметры)
POST /api/demo/create - Создать объект (JSON body)
PUT /api/demo/update/456 - Обновить объект
DELETE /api/demo/delete/789 - Удалить объект
