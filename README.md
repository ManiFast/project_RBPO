# Социальная сеть - Spring Boot приложение

## Тема проекта
Социальная сеть с возможностью публикации постов, комментирования, лайков и подписок.

## Основные сущности
- **User** - пользователь системы (с полями: id, username, password, role)
- **Post** - пост пользователя (связь ManyToOne с User)
- **Comment** - комментарий к посту (связи ManyToOne с User и Post)
- **Like** - лайк поста (уникальная связь User-Post)
- **Follow** - подписка пользователя на пользователя (уникальная связь follower-following)

## Операции сервиса

### Базовый CRUD:
- Регистрация и аутентификация пользователей
- Создание/редактирование/удаление постов
- Добавление/удаление комментариев
- Постановка/снятие лайков
- Подписка/отписка от пользователей

### Бизнес-операции (транзакционные):
1. **Лента подписок** - получение постов от пользователей, на которых подписан текущий пользователь
2. **Аналитика поста** - получение поста с количеством лайков и комментариев
3. **Рекомендации подписок** - предложение пользователей для подписки на основе социального графа
4. **Поиск по контенту** - поиск постов и комментариев по ключевому слову
5. **Деактивация пользователя** - каскадное удаление всех данных пользователя

## Технологический стек
- **Backend:** Java 21, Spring Boot 3.5.4
- **База данных:** PostgreSQL 16
- **ORM:** Spring Data JPA, Hibernate
- **Шаблонизатор:** Thymeleaf
- **Сборка:** Maven
- **Документация API:** Postman
