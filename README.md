# Социальная сеть - Spring Boot приложение

## Тема
Мини-социальная сеть с пользователями, постами, комментариями, лайками и подписками.

## Основные сущности
- **User** — пользователь (логин, пароль, роль)
- **Post** — пост (содержимое, автор, дата)
- **Comment** — комментарий к посту
- **Like** — лайк поста
- **Follow** — подписка на пользователя

## Бизнес-операции
1. CRUD для всех сущностей
2. Регистрация и аутентификация пользователей
3. Создание поста с автоматической привязкой к автору
4. Добавление комментариев к посту
5. Лайк/анлайк поста
6. Подписка/отписка на пользователя
7. Получение ленты новостей (посты тех, на кого подписан)
8. Статистика пользователя (посты, комментарии, лайки, подписчики)
9. Поиск постов по содержимому и автору
10. Рекомендации пользователей для подписки

## Технологии
- Java 17+, Spring Boot 3.+
- PostgreSQL
- JPA/Hibernate
- Thymeleaf (веб-интерфейс)
- Maven

## Запуск
1. Установите PostgreSQL, создайте БД `social_network`
2. Настройте `application.yaml` (или через env-переменные)
3. Запустите приложение: `mvn spring-boot:run`
4. Откройте http://localhost:8080

## API
Полная коллекция Postman в папке `postman/`
